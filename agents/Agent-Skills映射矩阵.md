# Agent-Skills 映射矩阵

## 矩阵总览

| Agent | 角色 | 核心产出 | 适用 Skills | 优先级 | 说明 |
|-------|------|--------|-----------|--------|------|
| **总调度** | 项目经理 | 项目报告、进度统计、验收报告 | pptx、docx、xlsx、dataviz | 中 | 汇总数据生成报表时有用 |
| **初始化** | 项目架构师 | 项目框架、配置文件、脚本 | docx、pptx | 低 | 可生成初始化指南文档 |
| **后端** | 后端工程师 | API 代码、数据库脚本、API 文档 | docx、xlsx、dataviz | 中 | 生成 API 文档、测试数据表、数据库关系图 |
| **前端** | 前端工程师 | React 代码、样式、UI 组件库 | **ui-ux-pro-max**、dataviz、pptx | **高** | 生成 UI 规范、界面预览、响应式演示 |
| **测试** | QA 工程师 | 测试报告、Bug 清单、性能数据 | xlsx、docx、dataviz、pptx | 高 | 生成测试报告、Bug 表、性能对比图 |
| **部署文档** | DevOps 工程师 | 部署脚本、部署指南、用户手册 | docx、pptx、dataviz | 中 | 生成正式文档、架构图、培训 PPT |

---

## 详细分析

### 1. 总调度 Agent（项目经理）

**核心职责：**
- 汇总各 Agent 产出物
- 生成项目进度报告
- 生成最终验收报告
- 管理风险和问题

**适用 Skills：**

| Skill | 使用场景 | 优先级 | 说明 |
|-------|---------|--------|------|
| **document-skills:pptx** | 项目周报、最终汇报 PPT | 中 | 每周生成项目状态 PPT |
| **document-skills:docx** | 项目验收报告、总结文档 | 中 | 生成正式的项目交付文档 |
| **document-skills:xlsx** | 项目进度表、任务统计表 | 中 | 整理各环节完成度、工作量统计 |
| **dataviz** | 进度图表、风险热力图、质量趋势 | 中 | 可视化项目进度、风险分布 |

**产出物示例：**
- 项目周报 PPT
- 项目验收报告 (docx)
- 进度统计表 (xlsx)
- 项目风险热力图

---

### 2. 初始化 Agent（项目架构师）

**核心职责：**
- 创建项目框架
- 配置开发环境
- 搭建项目目录结构
- 集成必要的库和工具

**适用 Skills：**

| Skill | 使用场景 | 优先级 | 说明 |
|-------|---------|--------|------|
| **document-skills:docx** | 项目初始化指南、技术选型说明 | 低 | 可选，如果需要正式文档 |
| **document-skills:pptx** | 项目架构设计 PPT（可选） | 低 | 可选，向团队讲解架构 |

**产出物示例：**
- 完整的项目框架代码
- package.json 配置
- 初始化指南 (docx，可选)
- 架构设计 PPT (可选)

---

### 3. 后端 Agent（后端工程师）

**核心职责：**
- 数据库设计和实现
- API 开发
- 业务逻辑实现
- API 测试和文档

**适用 Skills：**

| Skill | 使用场景 | 优先级 | 说明 |
|-------|---------|--------|------|
| **document-skills:docx** | API 接口文档、数据库设计文档 | 高 | 生成正式的 API 接口文档 |
| **document-skills:xlsx** | API 参数表、测试数据、字段映射表 | 中 | 生成 API 参数清单、测试数据导入表 |
| **dataviz** | 数据库关系图、API 流程图、架构图 | 中 | 生成数据库 ER 图、API 调用流程图 |

**产出物示例：**
- API 接口文档 (docx)
- 数据库设计文档 (docx)
- API 测试参数表 (xlsx)
- 数据库关系图 (PNG/SVG)

---

### 4. 前端 Agent（前端工程师）⭐

**核心职责：**
- 页面组件开发
- UI 样式和布局
- 用户交互实现
- 组件库集成

**适用 Skills：**

| Skill | 使用场景 | 优先级 | 说明 |
|-------|---------|--------|------|
| **ui-ux-pro-max** | **UI 设计规范、界面预览、响应式演示** | **⭐⭐⭐ 高** | **最重要！用于生成设计规范和界面预览** |
| **dataviz** | 交互流程图、页面布局图、组件关系图 | 中 | 生成页面逻辑流程图、组件依赖图 |
| **document-skills:pptx** | 前端架构 PPT、组件库介绍 | 低 | 可选，用于团队分享 |

**ui-ux-pro-max 的具体应用：**
```
环节3完成后：
1. 生成 UI 设计规范文档
   - 颜色方案、排版规则、间距标准
   - 组件库使用指南
   
2. 生成界面预览
   - 不同屏幕尺寸下的界面展示（PC、平板、手机）
   - 交互状态演示（hover、active、disabled）
   
3. 用户审核支持
   - 生成视觉效果对比
   - 演示响应式布局
```

**产出物示例：**
- UI 设计规范文档
- 界面预览图（多屏幕）
- 响应式演示 HTML
- 交互流程图
- 前端架构 PPT (可选)

---

### 5. 测试 Agent（QA 工程师）

**核心职责：**
- 功能测试执行
- Bug 识别和记录
- 性能测试
- 测试报告生成

**适用 Skills：**

| Skill | 使用场景 | 优先级 | 说明 |
|-------|---------|--------|------|
| **document-skills:xlsx** | Bug 清单表、性能数据表、测试用例表 | 高 | 生成结构化的 Bug 和性能数据 |
| **document-skills:docx** | 测试总结报告、缺陷分析报告 | 高 | 生成正式的测试报告 |
| **dataviz** | Bug 分布图、性能对比图、测试覆盖率图 | 高 | 可视化测试结果、性能指标、Bug 热力图 |
| **document-skills:pptx** | 测试总结 PPT、质量评审演讲 | 中 | 向管理层汇报测试结果 |

**产出物示例：**
- 测试报告 (docx)
- Bug 清单表 (xlsx)
- 性能数据表 (xlsx)
- Bug 分布热力图
- 性能对比图表
- 测试总结 PPT

---

### 6. 部署文档 Agent（DevOps 工程师）

**核心职责：**
- 编写部署脚本
- 编写部署指南
- 编写用户文档
- 编写 FAQ 和故障排查指南

**适用 Skills：**

| Skill | 使用场景 | 优先级 | 说明 |
|-------|---------|--------|------|
| **document-skills:docx** | 部署指南、用户手册、FAQ | 中 | 生成正式的 Word 版文档（可配合 Markdown） |
| **document-skills:pptx** | 部署培训 PPT、架构讲解 | 中 | 用于部署前的团队培训 |
| **dataviz** | 系统架构图、部署流程图、监控仪表板 | 中 | 生成部署拓扑图、监控架构 |

**产出物示例：**
- 部署指南 (docx)
- 用户手册 (docx)
- FAQ 文档 (docx)
- 系统架构图
- 部署流程图
- 部署培训 PPT

## 使用优先级建议

### 🔴 必用（高优先级）
- **前端 Agent + ui-ux-pro-max** - 界面预览和设计规范
- **测试 Agent + dataviz** - 可视化测试结果
- **测试 Agent + xlsx** - 结构化的 Bug 和性能数据

### 🟡 推荐使用（中优先级）
- **后端 Agent + docx** - API 文档
- **部署文档 Agent + docx** - 正式部署指南
- **总调度 Agent + dataviz** - 项目进度可视化

### 🟢 可选使用（低优先级）
- **初始化 Agent** - 主要写代码，skills 用处不大
- **各 Agent + pptx** - 内部分享和汇报时使用

---

## 实施建议

1. **第一阶段**（必须）
   - 前端 Agent 配置 ui-ux-pro-max
   - 测试 Agent 配置 xlsx + dataviz + docx

2. **第二阶段**（推荐）
   - 后端 Agent 配置 docx + dataviz
   - 部署文档 Agent 配置 docx + dataviz

3. **第三阶段**（可选）
   - 总调度 Agent 配置汇总类 skills
   - 其他 Agent 按需配置
